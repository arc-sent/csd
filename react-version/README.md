# ChessLab — версия на React + Tailwind

Та же вёрстка лендинга, что и в корне проекта, перенесённая на React 18, Vite 6
и Tailwind CSS 4. Разметка, тексты, брейкпоинты и поведение тренажёра совпадают
с исходной версией.

## Запуск

```
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр собранной версии
```

## Структура

```
src/
  data/level.js        уровень: позиция и алгоритм решения (пары ходов, ТЗ 3.2)
  lib/chess.js         правила ходов, координаты, спрайты фигур
  hooks/useTrainer.js  экран решения задачи целиком (ТЗ 4.3)
  components/
    Board.jsx          доска и рамка с координатами
    Demo.jsx           блок «Интерфейс» — рабочий тренажёр
    Hero.jsx           первый экран и витрина интерфейса
    Sections.jsx       «Для кого», «Как это работает», «Почему», тарифы, отзывы
    Faq.jsx            FAQ, финальный блок и подвал
    Header.jsx         шапка с бургер-меню
    Marquee.jsx        бесконечная бегущая строка
    Reveal.jsx         появление блоков при прокрутке
    ui.jsx             кнопки, контейнер, заголовки секций
  index.css            токены дизайна, стили доски и анимаций
```

## Что осталось обычным CSS

В `index.css` живут клетки доски, метки допустимых ходов и подсветка подсказки.
Это псевдоэлементы с процентными размерами внутри клетки — утилитами Tailwind
они не выражаются. Всё остальное оформление сделано классами Tailwind.

Токены дизайна вынесены в `@theme`, поэтому цвета и шрифты доступны как обычные
утилиты: `bg-ink`, `text-accent`, `font-display`. Точки перелома совпадают с
исходной версией: `sm` — от 641px, `lg` — от 981px.

## Тренажёр

`useTrainer` держит историю позиций (кнопки «Назад» и «Вперёд»), проверяет ход по
алгоритму уровня, проигрывает ответ соперника и анимирует перемещение фигуры
через Web Animations API. Ход делается тапом «откуда → куда» или перетаскиванием.
