# ChessLab — landing prototype

Статический макет лендинга платформы для решения шахматных задач.

## Файлы
- `index.html` — структура страницы и контент.
- `styles.css` — визуальная система и адаптивная вёрстка.
- `script.js` — меню, FAQ/native details, интерактивные кнопки, анимации появления и макет шахматной доски.

## Запуск
Открой `index.html` в браузере или подними локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.
